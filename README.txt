# Funngro Website Revamp — concept prototype

This is an independent concept redesign for the Funngro Website Revamp project.

## Files
- `index.html` — landing page / overview
- `company.html` — page for companies
- `teen.html` — page for teens
- `style.css` — responsive styling
- `SEO_Audit_Report.pdf` — preliminary SEO audit report

## Publish using GitHub Pages (phone-friendly)
1. Create a **public** repository on GitHub, e.g. `funngro-website-revamp`.
2. Upload all HTML/CSS files from this folder to the repository root.
3. Open repository **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
5. Wait for deployment and open the published site link.

Important: before submission, replace `https://example.com/` canonical URLs with the actual published URL. This is a concept prototype and is not an official Funngro site. Confirm project rules permit independent concept work and public hosting.
